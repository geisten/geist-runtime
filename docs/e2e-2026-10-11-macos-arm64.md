## Findings

1. **H12/long prefill (#146):** SIGTERM and a closed connection do not end a long prompt; the 0.3.0 note says SIGTERM "ends the running answer at once". A kill leaves the socket file (expected for SIGKILL).
2. **A2 (#148):** pinned releases are not on the download server (v0.1.1, v0.3.1 → 404), `install.sh` prints only curl's error.
3. **B5 (#149):** a corrupted file and an outdated file look the same in `catalog` (`⟳ not this catalog's file`).
4. **Verify through a symlink (#151):** a symlink to a verified model in another models folder gave "does not match the catalog" while a `cp -c` copy passed. Seen once, not analysed.
5. **`--files` sources (#150):** `sources: a.md, b.md` listed `b.md`, which had nothing to do with the question (only two chunks existed).
6. **Option order:** `geistr --models DIR run …`, `geistr run … --models DIR` both work; the usage text puts options last. No problem found (recorded because the first attempt failed from a shell error of the tester).
7. **Small model repeats itself:** Qwen3 0.6B at temperature 0.7 answered "Say hello." and an essay request with the first answer again (context copying); the loop guard did not fire (G9 was not run with SmolLM2).
8. **Default port 11434** is the Ollama port; people with Ollama get a clear error, and `--http=ADDR:PORT` works around it.
9. Plan: cases for features since 0.1.2 were missing (now section L); the plan's tmux helpers use `$T` as a command string, which breaks in zsh (use a function).
